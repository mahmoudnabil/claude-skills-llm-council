# Mode: rebuttal (responding to real reviews)

Plans the response to real reviewer comments: what to concede, clarify,
push back on, or run new work for, under the rebuttal word or page limit
and the revision deadline.

## Extra brief fields

- Reviews, split into individually numbered comments: `R1.1`, `R1.2`,
  `R2.1`, ... (number them in the brief if the venue did not). Include the
  meta-review or AE summary as `AE.1`, ... when present.
- Decision so far (major revision, reject and resubmit, conference
  rebuttal phase) and the venue rules: rebuttal length, whether new
  results are allowed, revision page limit, deadline.
- Paper files (current version) so advisors can check whether a comment is
  already answered in the text.
- Any experiments or data the authors already have but did not report.

## The five lenses

**Seat 1, Hostile Reviewer (Contrarian).** Reads each response plan as the
toughest reviewer would. Which comments expose a real weakness that a
"clarify" answer will not survive? Where would pushing back look
defensive? Which reviewer is most likely to hold a low score, and why?

**Seat 2, Methodologist (First Principles).** For each technical comment,
decides whether the reviewer is right on the merits. Separates
misunderstandings (fix the text) from real gaps (fix the work). Identifies
the minimum new experiment or analysis that would settle a disputed point.

**Seat 3, Area Chair (Expansionist).** Reads all reviews together, the way
the AE or AC will. Finds the two or three themes that drive the decision.
Spots comments that, answered well, strengthen the paper beyond the
original submission. Flags where reviewers disagree with each other and how
to use that.

**Seat 4, Outsider (tone and clarity).** Checks that each planned response
is understandable without the paper open, answers the question actually
asked, and stays courteous and specific. Flags responses that would read as
evasive, dismissive, or vague.

**Seat 5, Revision Editor (Executor).** Costs each response: text-only
change, new figure or table, new experiment, and the page-budget impact.
Proposes what to cut to make room. Builds a schedule that fits the
deadline.

## Response classes

Every comment gets exactly one class:
- **Concede**: reviewer is right; change the paper.
- **Clarify**: reviewer misread; the text caused it; rewrite the text.
- **Push back**: reviewer is wrong on the merits; explain with evidence.
- **New experiment**: the point needs new results to resolve.

## Extra peer-review question

4. Which comment has the wrong class in at least one response, and what
   should the class be?
